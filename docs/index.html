contacts

Contacts management

Get all contacts

Retrieves a paginated, sorted, and filtered list of contacts for the authorized user.

Authorizations:
bearerAuth
query Parameters
page
integer >= 1
Default: 1

Page number for pagination

perPage
integer >= 1
Default: 10

Number of items per page

sortBy
string

Field to sort by (e.g. name, createdAt)

sortOrder
string
Enum: "asc" "desc"

Sort order (asc or desc)

contactType
string
Enum: "work" "home" "personal"

Filter by contact type

Responses

http://localhost:3000/contacts
https://nodejs-hw-mongodb-a7nh.onrender.com/contacts
